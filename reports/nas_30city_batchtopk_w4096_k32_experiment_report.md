# 30 城市街景 BatchTopK SAE 实验报告

**版本：** NAS 替代图像批次；DINOv3 ViT-B/16；BatchTopK SAE W4096、K=32。
**状态：** 训练、全量推断与现有图件分析完成；语义验证和统计显著性检验尚未完成。
**核对日期：** 2026 年 10 月 13 日。

## 摘要

本实验检验能否从跨城市街景的 DINOv3 patch 表征中学习一个比输入空间更宽、同时保持稀疏的 SAE 字典，并用它描述图像与城市的视觉组成。30 个城市共选出 92,692 个具备位置元数据和完整四方向照片的全景点位。小型质量筛选器排除 1,767 个点位，保留 **90,925 个点位、363,700 张方向图像**。冻结 DINOv3 生成每张图的 196 个 768 维 patch token；BatchTopK SAE 的字典宽度为 4,096，批级稀疏预算 K=32。

10 个 epoch 后，抽样验证集的平方 L2 重建损失从 **0.129676** 降至 **0.109847**，余弦相似度从 **0.933020** 升至 **0.943644**。这说明模型在该验证抽样下学到了可重建输入 token 的稀疏表示；它单独不能证明每个维度具有稳定、互不重复的人类可解释语义。

## 1. 问题和边界

本实验分别考察：① 稀疏字典能否重建 DINOv3 patch；② 激活能否映回原始方向图像、描述图像和城市组成；③ 字典簇之间是否出现可描述的共同激活与城市差异。

这批图像与旧 Feature-MAE 图像**不重合**。旧 JPEG/TAR 和特征缓存未挂载，因此这是沿用旧实验问题设置的新 SAE 实验，不能做逐图配对，也不能由此判断 SAE 优于 Feature-MAE。本次输入是 **224 × 224 像素、14 × 14 patch 网格**，不是曾讨论的 28 × 28 网格。

## 2. 数据和质量筛选

| 项目 | 数量 |
|---|---:|
| 城市 | 30 |
| 初始全景点位 / 四方向图像 | 92,692 / 370,768 |
| 筛除全景点位 / 图像 | 1,767 / 7,068（1.91%） |
| 保留全景点位 / 图像 | 90,925 / 363,700 |
| 训练图像 / 验证图像 | 348,340 / 15,360 |

每个点位必须同时具有 0°、90°、180°、270° 四张照片和经纬度。目标是每城 3,200 点；初始清单中柏林只有 569 点、芝加哥 2,523 点。质量门在全景点位级判断：四图中出现黑图，或至少两图呈高可信隧道特征时，整组排除。质量日志记录 1,748 个黑图标记、21 个隧道标记，两类可能重叠。筛选器在全部 30 城加载了模型，但该模型基于弱标签与合成校准样本，隧道识别仍需人工标注集检验。

每城随机留出 128 个**点位**，其四个方向都进入验证集；总计 3,840 个留出点位。同一全景不跨训练与验证，但切分没有按街区或空间缓冲区隔离，邻近街道仍可能跨集。

## 3. 特征提取与 SAE 训练

冻结的 DINOv3 ViT-B/16 **分别**编码每个方向图像，产生 196 个 L2 归一化的 768 维 patch token。四个方向没有在 SAE 输入前拼接，也没有通过跨方向注意力联合建模；四向拼接只用于后续查看同一个全景。

对于一个 token $x\in\mathbb{R}^{768}$，模型计算

$$
z=\operatorname{ReLU}(W_{\mathrm e}(x-b)+b_{\mathrm e}),\qquad
h=\operatorname{BatchTopK}_{32}(z),\qquad
\hat{x}=W_{\mathrm d}h+b.
$$

BatchTopK 在整个批次的 $B\times4096$ 个激活中保留至多 $32B$ 个最大正值。因此 K=32 是**批平均**稀疏预算，不表示每个 patch 恰好激活 32 维。目标是批均值平方 L2 重建误差；每次更新后把解码器方向归一化。

| 设置 | 值 |
|---|---:|
| 输入维度 / 字典宽度 / 批级 K | 768 / 4,096 / 32 |
| 每步每城图像 / 每图 patch | 4 / 32 |
| 每步 token 总数 | 3,840 |
| 每轮步数 / 轮数 | 3,200 / 10 |
| 优化器 / 学习率 / 权重衰减 | AdamW / 3×10⁻⁴ / 10⁻⁵ |
| 梯度范数上限 / 随机种子 | 1.0 / 42 |

训练按城市均衡采样：每轮每城取 12,800 次方向图像，短样本城市会重复抽取。故每轮 1,228.8 万次 patch 抽样是**抽取次数**，不是独立样本数量。验证每轮固定使用 8 批抽样 token，每批每城 2 张图、每图 64 个 patch，合计 30,720 次 patch 抽样。验证损失不是全部留出 patch 的精确均值。

## 5. 字典与描述性分析

### 字典层级和激活区域

把 4,096 个解码器方向按余弦距离做平均链接层级聚类，并切成 32 簇、64 簇。64 簇的成员数最小 6、中位数 37.5、最大 426，说明几何聚类的簇大小不均。这不是特征激活率，也不能直接解释为语义类别大小。

全量推断中，一张图的某个字典维度分数取其 196 个 patch 激活中的最大 20 个的均值。空间和共现分析另将每个 patch 的最大正激活维度映射到 64 簇，再计数。映回原图的颜色标示**模型获胜 patch 的位置**，不是像素级语义分割真值。

![四方向原图与两簇激活叠图](../outputs/experiments/nas_30city_batchtopk_w4096_k32/figures/Fig_Image_Level_Atypical_Coactivation.png)

### 图像共现和城市差异

严格同图共现要求两个簇分别在同一张**方向图像**中赢得至少 4 个 patch。支持度至少 500 张图像的簇对有 1,039 对。例如 F19 与 F46 共现 571 张，按全局边际频率独立计算的期望约为 95.4，正点互信息 PPMI 约 2.58 bit。这只是描述性独立模型，没有控制城市、相邻点位等混杂因素；**PPMI 不是显著性检验的 p 值**。

城市相对其他城市的簇对富集也可描述：Dhaka 的 F33+F44 在 12,800 张图像中出现 633 次（4.95%）；其余城市合计 296 次（约 0.084%），频率比约 58.6。这说明编号簇对在当前样本中集中于 Dhaka；尚未经语义标注、点位级统计推断和多重比较校正，不能直接命名为具体建筑或景观。30 城市在 64 簇组成向量上的两两余弦相似度中位数约 0.951，范围约 0.689–0.997；这些是该粗粒度编码下的相似度，不能推断具体街景近乎相同。

![城市特征组合的相对富集](../outputs/experiments/nas_30city_batchtopk_w4096_k32/figures/Fig_City_Specific_Atypical_Combinations.png)

### 城市空间结构

先按点位合并四方向的 64 簇计数，再聚合到 1 km Web Mercator 网格，要求每格至少 5 个点位。城市同质性定义为有效网格两两归一化组成向量的平均余弦相似度；局部连续性定义为水平或垂直相邻网格的平均余弦相似度。

30 城市都生成了表格，但只有 21 城达到**至少 20 对相邻有效网格**的绘图门槛。在这 21 城中，同质性约为 0.857–0.969，局部连续性约为 0.919–0.979。其余 9 城保留在 CSV；有些只有 0–2 对相邻网格，其连续性不宜解释为稳定的城市指标。尚无空间置换检验或置信区间。

![城市同质性与相邻网格连续性](../outputs/experiments/nas_30city_batchtopk_w4096_k32/figures/Fig_Homogeneity_vs_Local_Continuity.png)

## 6. 与旧图关系及局限

实验输出 **29 组新图**。旧 Feature-MAE 的 37 个图名中，25 个具有 SAE 对应图；“有对应图”只表示同一研究问题获得了新图，**不表示指标完全相同**。旧 E+D+P 关系图由解码器余弦层级代替；旧 512 维分析由 4,096 个 SAE 维度或 64 个簇代替；部分旧图包含的三元组和空间占比并未重现。剩余 12 张需独立的图原型、布局或 Mask2Former 分割分析，没有复制旧图冒充新图。逐图差别见图件清单。

### Chapter 5 重绘图件

为论文另绘制了 10 张同一批次的图，源文件位于 `outputs/experiments/nas_30city_batchtopk_w4096_k32/figures/chapter5/`，论文副本位于 `/root/code/HKUST-Thesis/img_gene/nas30_w4096/`，并在 `05_research3.tex` 的独立小节引用。图件对应 Chapter 5 的问题顺序：城市样本、训练损失、图像组成 UMAP、字典层级、共享与城市富集、城市组成、城市相似度、图像共现、城内空间结构，以及四方向全景激活实例。

其中 UMAP 投影的是**方向图像的 SAE 簇组成**，不是旧图的 DINO patch；层级只使用**解码器余弦距离**，不是旧版 E+D+P 融合；空间图只展示达到相邻网格门槛的 21 城，未复现旧版空间地图或 Moran's I。共现图采用每张方向图像的 top-8 簇与自然对数 PPMI，联合支持度低于 182 张图的簇对设为零。四方向在点位统计和展示时合并，编码及 SAE 输入仍是逐张方向图像。

按旧文同一共享规则重新计算，**17/64** 个簇满足条件，合计贡献 **85.39%** 的等城市权重平均 patch 响应；各城与其余城市均值的组成重叠为 **74.99%–90.26%**。这些值只属于新批次。旧文的 32/64、93.94% 和 296,409 点位属于另一套城市、图像及模型，不能把两批差异归因于字典宽度，也不能共用图注。新批次没有完成独立语义验证、显著性检验或旧论文的外部效度评估。

目前最关键的局限是：① 未系统评估字典维度的语义一致性与重复性；② 共现、城市富集和空间连续性仍是描述性统计；③ 缺少同图像 Feature-MAE 基线、宽度/K/随机种子的当前批次消融；④ 四方向未联合建模；⑤ 城市不是概率抽样，质量筛选器尚缺独立人工标注审计。

## 7. 当前结论和建议检验

**可以确认：** W4096/K32 BatchTopK SAE 已在这批街景 DINOv3 patch 上完成稀疏重建训练，能够把编号簇的激活区域映回原图，并生成可复查的城市组成与共现表。

**不能确认：** 4,096 个维度都有清晰、稳定、互不重复的语义；PPMI 较高的簇对就是统计显著的街景模板；SAE 相比旧 Feature-MAE 更好。

下一步宜在按**点位**划分的独立样本上抽取每维 top 激活区域，进行盲法语义标注和重复维度分析；再按城市分层、以点位为置换单位构造共现零分布，对事先选定的组合报告效应量、置信区间与 FDR 校正。若核心问题是四向全景的空间组合，需另外训练跨方向联合模型，与当前独立方向模型比较。
