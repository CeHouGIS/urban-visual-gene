视觉基因图谱 · K=512 全球12城字典

全球字典训练于香港·新加坡·阿姆斯特丹·开普敦·巴黎·圣保罗·墨西哥城·悉尼·雅加达·达卡·新德里·马尼拉 （6 大洲 12 城，1152 万 patch @448）。把 512 个基因按解码器方向 KMeans 聚成 10 个类别； 每行是一个类别的代表基因在真实街景上的定位（红区 = 该基因点亮的 patch）。类别名是人工事后粗解读，不参与训练——粒度所限类别间有语义重叠。

去偏训练。 为让这本"共享字典"公平、无城市偏向：① 每城等量采样（不按城市大小成比例，否则大城主导）； ② 城内按路网/采样点密度分层（压掉 GSV 在主干道的过采）；③ 每个 pano 的全部 4 个朝向都进训练（朝向无偏）； ④ 修复了 DINOv3 的边界 artifact（方向投影剔除）和一处目录大小写 bug（曾静默漏掉约 79% 的 pano）。 结果：0 死原子、12 城严格等量。仅存的数据源偏差（GSV 本身偏发达城市/主干道）无法从采样端消除，须在结论中声明。

从基因到城市 · 街道形态型

把可解释的基因逐级往上聚合，就能回答"城市由哪几类街道组成"。 每个 patch 取主导基因 → 一个点的 4 个朝向 (0/90/180/270) 拼成 56×14 全景基因图 → 按高度带（天空/上部/中部/地面）数基因直方图得到组成 → 沿路网把同一街段的点池化 → CLR → PCA → KMeans 聚成街道形态型。全程无空间项、无人工标注。

正式版：四城 240 条街道，K=512 共享字典 @448，联合聚类成 6 个形态型。 用同一本字典把香港/新加坡/阿姆斯特丹/开普敦放到同一个基因空间里， 形态型立刻分出城市特异型与跨城共享型：

🌍 type 1 · 开普敦独有（郊区干道） 🌴 type 3 · 新加坡独有（绿荫路） 🚲 type 4 · 阿姆斯特丹独有（乡野/自行车道） 🚇 type 0 · 跨城共享（隧道） 🛣️ type 2 · 跨城共享（高速/高架）

地图上同型的点在地理上自发成片、且城市间组成差异显著——而流水线里没有放任何空间/地理/城市标签， 这正是"空间连贯性 + 跨城可迁移"作为可解释性忠实性证据的体现：结构不是喂进去的，是从共享视觉基因里长出来的。

注：每城按"四朝向覆盖最全"选 60 条街，偏向车载主干道，故隧道/高速型占比偏高；均衡采样后住宅街/商业街等会更丰富。

字典粒度 · K 扫描

正式跑用四城 320 万个 patch @448 扫了 K=256 / 512 / 1024 三组字典（topk=32）。 三组全部零死原子——数据量支持到 1024 都不浪费。重建随 K 微升（0.912→0.926→0.936）， 但更大的 K 主要是把概念语义细分、不是空间分辨率更细（下图每图基因数在三组间相近）。 权衡可解释性与保真度，正式版选 K=512。

字典：12 城全球版（6 大洲 / 448² / K=512, L0=32, 1152 万 patch, 零死原子）。 DINOv3 ViT-L/16 @448（28×28=784 patch），去偏共享 Top-K SAE。 方法论要点：稀疏用 Top-K 硬约束（软 L1 会退化成稠密激活）；训练损失里不放空间平滑项， 好让"空间连贯性 + 跨城可迁移"作为独立忠实性证据；边界 artifact 用方向投影从根上剔除（边界一致性 90%→10%）。 下方"街道形态型 / 街道浏览器"两节为城市级应用（目前用有路网数据的 4 城做街段分析；9 个新城已入字典，做街道级需另跑路网匹配）。 下一步：Vienna 下载完成后补入字典（现已 32% 且在下）、更细的基因级命名、更多城市的街道级分析。
