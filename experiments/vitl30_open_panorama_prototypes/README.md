# 完整四方向全景：开放式景观模式挖掘

下一轮“跨街景重复的局部要素组合”方案见 [LOCAL_COMPOSITION_DESIGN.md](LOCAL_COMPOSITION_DESIGN.md)。当前 18 个模板属于完整全景重建探索结果，不是已经验证的局部景观组合。

## 目标和状态

取消局部矩形候选和固定32槽位。一个样本是同一点位的四张方向图；复用冻结的 ViT-L、W4096/K32 SAE 激活，不重新提取 DINO 特征或训练 SAE。

方向顺序为0、90、180、270度，正确拼接为28×112的环形网格；270度与0度相邻。方向图来自透视相机，横排展示不代表经过无缝球面投影。

## 可恢复的探索流程

1. 沿用已有1km空间块划分：60,233训练、12,755开发、13,050测试全景。测试激活及图片在本轮保持封存。
2. 使用全部4096维的正激活及仅训练集计算的RMS，将其按既有64个decoder组求和并按组大小平方根缩放。每方向内部2×2均值池化后，输入为64×14×56。没有筛掉无UMAP坐标的SAE维度。
3. 在完整环形输入上学习非负稀疏字典。四种90度环形旋转共享模板。原型从少量训练样本开始，训练残差中重复、跨城市的结构产生新模板；高度相似的模板旋转对齐后合并；低支持模板淘汰。最终数量不固定。
4. 开发集监测重建、支持度及每方向patch重建覆盖。发布全景原图、贡献mask和原型生命周期记录，不使用旧版本实例占位。

64组聚合与2×2池化是第一轮计算近似；这里的覆盖率是组级重建覆盖，不是4096维原始激活覆盖，更不是语义解释覆盖。原始稀疏激活保留。后续须检查组内混合、不同分辨率、随机种子、打乱对照及人类语义核查。冻结SAE和已有VLM解释曾见过部分新划分中的图像，空间隔离仅针对新增原型层。

## 运行

```bash
python -u -m experiments.vitl30_open_panorama_prototypes.code.run --device cuda:1
```

CPU仅做稀疏缓存整理；模型优化必须使用CUDA，无GPU时明确退出。输出、进度、可恢复检查点均在本目录outputs/，不进入Git。

默认探索参数：12轮，初始化4个模板，每2轮探索出生/合并/淘汰，候选至少6个训练全景且跨3城，旋转对齐余弦相似度0.97可合并。候选相似性阈值取0.30和训练残差内部位置打乱余弦的99.5分位数中的较大值；这是候选阈值校准，不是独立显著性检验。96仅是本次内存与计算上限，不是景观类别数；达到上限必须在报告中标记饱和，不能声称发现了自然的类别总数。

每次出生必须改善固定开发面板的重建；全开发集用于选择检查点。统计检验、独立语义核查与最终测试尚未完成。

## 2026-10-16 首轮结果

- GPU 1完成12轮；从4个初始化模板出发，产生14次新模板，最佳第8轮保留18个。未触发合并或淘汰，未达到96的资源上限。
- 使用60,233训练全景；12,755个开发全景的组级归一化重建NMSE为0.3736，平均使用3.54个模板。
- 64组、14×56池化网格的平均重建覆盖为87.1%；四方向分别至少80%网格达标的全景占53.3%。**这不表示全部图像已达标，也不是原4096维或语义解释覆盖。**
- 每个候选导出6组开发集实例，共108组；展示四方向原图、贡献份额热图和阈值0.35的mask。部分mask覆盖全图，少数实例没有达到mask阈值；不得解读为精确物体分割。
- 原有特征提取直接将每张方向图缩放到方形，没有中心裁剪；展示时将网格缩放回完整原图，保留原图显示比例。方向排序及patch网格拼接已测试。
- 初始固定残差余弦阈值0.75未产生新候选，旧尝试保存在outputs/attempts/strict_similarity075/。本轮使用训练集位置打乱校准阈值，不构成独立统计检验。
- 独立语义核查、跨种子、打乱对照、分辨率/聚合误差及停止规则仍待验证；13,050个测试全景保持封存。
