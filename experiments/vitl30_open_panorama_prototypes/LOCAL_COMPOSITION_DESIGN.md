# 下一轮实验：跨街景重复的局部要素组合

状态：**实验设计，尚未训练或验证。**现有的 18 个完整全景模板仅作为旧方法对照，不计为已发现的景观组合。

## 研究对象

- **局部要素实例**：一张方向图中有形状的 patch 集合及其 SAE 激活，例如一段建筑立面或一片树冠。它有原图 mask、4096 维稀疏激活摘要、DINO 表征和全景中的方位。
- **组合原型**：至少两个不同的要素实例，以及它们可重复的相对关系。实例可位于同一方向或跨越多个方向；不要求落在某个矩形框内，也不固定在全景的绝对朝向上。
- **原型实例**：一个全景中匹配该组合的一组区域 mask。统计支持度时，一个完整全景最多计一次，并同时记录独立的 1 km 空间块和城市数。

目标是发现“不同地方也反复出现的要素及关系”，而不是找一个能重建大部分全景背景的模板。原型可以部分匹配一幅街景；剩余部分留给其他原型或标为未解释。

## 输入和划分

复用冻结的 ViT-L、BatchTopK SAE W4096/K32 和已有逐 patch 稀疏激活；不重新提取 DINO，也不重训 SAE。以同一点位的四方向图作为一个样本，顺序为 0°、90°、180°、270°。每方向保留 28×28 patch 和原始 4096 个维度的身份；不用当前完整全景模板的 64 组、14×56 池化表示作为组合训练的唯一输入。

沿用现有空间块划分：60,233 个训练全景、12,755 个开发全景、13,050 个测试全景，覆盖可核验映射的 29 城市。开发集只用于选阈值和模型；原型、要素类别和解释不得从测试图像生成。由于冻结 SAE 此前可能见过部分这些图像，这种隔离仅能证明**新增组合层**的泛化。

## 第一步：从 patch 找局部要素

1. 在每张方向图的 28×28 网格上，用归一化 SAE 激活余弦相似度、DINO patch 相似度和网格邻接关系形成图。SAE 只用非零值参与匹配，保留维度编号与强度。
2. 从图的连通/社区结构产生大小自适应的区域候选；可用图像分割模型提供轮廓候选，但分割结果并非语义真值。无把握的区域标为未确定，不能强行归入一个物体。
3. 先处理同一物体的部件关系：包含、强重叠或共同运动式的区域可以归入一个父区域，同时保留子区域。比如“墙面+窗户”首先作为建筑立面候选，不应仅凭两个部件的共现就成为景观组合。
4. 对每个候选区域存储原图 mask、pool 后的 4096 维 SAE 摘要、区域 DINO embedding、主导 SAE 维度和所属方向/角度。跨方向边界只在图像证据支持接续时合并；0° 与 270° 按环形关系处理。

本阶段应人工核查跨城市抽样的区域是否完整、是否过分碎片化，特别检查墙面/窗户、树干/树冠、道路/车道线。若区域层有系统误差，后续不能把组合命名为景观原型。

## 第二步：将四方向组成一个关系图

每个全景形成图 G=(V,E)：节点是上述局部要素，边记录相邻、上下、相对方位、相隔角度及共同可见等关系。角度使用模 360° 的差值；同时存储各节点的形状和 4096 维激活。关系允许跨方向，也允许相距较远，但必须在真实图像中有可检查的实例。

组合比较使用相对角度和相对位置，允许整幅全景旋转 0/90/180/270°，并容忍有限的尺度与位置变化。这样一个“道路—树列—建筑界面”模式可以在不同朝向、不同街景中匹配，不必为每个绝对方位学习一份模板。

## 第三步：开放式发现并训练组合

1. **候选生成**：在训练集的不同全景中寻找重复的二元/三元关系作为种子，再逐步增加有贡献的节点及关系。不预设最后的原型数量，也不规定一个局部矩形尺寸。离散化关系用于快速检索；最后始终回到连续的 4096 维激活和原图区域核查。
2. **软匹配**：每个候选原型包含可学习的节点激活中心、区域表征及关系分布。对一个全景，在节点与关系之间找最佳对应，允许环形旋转和少量位置形变；匹配分数必须同时奖励要素相似与关系相似。
3. **交替更新**：用高置信匹配实例更新原型的节点和关系分布，再重新搜索实例。新原型只有在开发集带来独立收益时保留；重复原型合并，低支持或不稳定原型淘汰。
4. **复杂度控制**：用模型复杂度与实例解释收益之间的权衡决定是否继续扩展；显式记录资源上限。如果触及上限，只报告搜索受限，不称其为自然类别数。

组合必须包含至少两个**不同父区域**的贡献；同一父对象内的多个部件只作为单元内部结构。组合的名称由代表实例与事后 VLM 辅助解释产生，VLM 名称不参与自动训练目标。

## 第四步：判断它是不是重复的景观组合

- **重复性**：分别报告训练、开发集的全景数、1 km 空间块数、城市数及每城出现率。一个城市大量重复采样不能替代跨城市证据。具体支持阈值只在训练/开发集校准。
- **超过偶然共现**：在同城不同空间块间置换要素实例，保留每类要素的城市频率，测试共现是否仍出现；另在全景内部打乱相对位置，测试原型是否依赖真实布局。对多个候选做多重检验校正。
- **稳定性**：换随机种子、重抽训练城市和空间块后匹配原型，检查组成维度、关系与代表图片是否保持一致；再看留出城市上的检索结果。
- **反事实**：移除一个组成要素或改变其相对位置，原型分数应有可解释的下降；只保留同一物体部件的版本不应通过景观组合检查。
- **图像证据**：每个保留原型展示来自不同城市与点位的实例，四方向原图分别标记各要素 mask，并列出主导 SAE 维度、关系、匹配置信度与失败例。

原先的“80% patch 覆盖”单独评估：只有被已验证原型匹配的有效 patch 才计入语义覆盖；同时报告每全景四方向最低覆盖、达标全景比例与置信区间。64 组池化重建覆盖不能代替该指标。

## 执行顺序与通过条件

1. 先在覆盖所有 29 城的**训练集抽样**上生成局部 mask 与四方向图，人工核查部件合并和跨方向关系，输出有错误类型的审阅表。
2. 在同一抽样上生成和匹配组合，展示至少若干个跨城市的多要素实例及零假设对照，再确定阈值；若结果仍以背景或单对象部件为主，先修复局部要素层。
3. 再跑全部训练与开发全景，锁定原型后仅一次性使用封存测试，单列新增组合层的泛化结论。

旧的完整全景模板页面在新组合通过检查前只保留“重建基线/探索”身份，不把 18 个候选当作景观类别。

## 方法依据

- Locatello 等，*Object-Centric Learning with Slot Attention*：从图像表征中形成对象式要素的参考；本方案不用固定 slot 数作为最终景观种类数。
- Ravi 等，*SAM 2*：提供候选区域轮廓的可选工具；分割 mask 仍需由 SAE 激活和人工样本核查。
- Yan 与 Han，*gSpan*；Cook 与 Holder，*Substructure Discovery Using Minimum Description Length and Background Knowledge*：重复子图搜索与复杂度控制的参考。离散子图仅用于候选召回，最终应以原图和连续激活验证。
